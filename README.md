# AI壁打ち

同じ問いを ChatGPT、Claude、Gemini に送り、回答と考え方の違いを縦に読み比べる個人用アプリです。これは「正解」や「ベスト回答」を決めるものではなく、自分で考える材料を集めるためのツールです。

## 初回セットアップ

### 1. Python を確認する

ターミナルを開き、次を実行します。

```bash
python3 --version
```

Python 3.10 以上なら進めます。

### 2. 必要なライブラリを入れる

このフォルダに移動して、次を実行します。

```bash
python3 -m pip install -r requirements.txt
```

### 3. APIキーを設定する

`.streamlit/secrets.toml.example` をコピーして、同じ `.streamlit` フォルダ内に `secrets.toml` を作成します。次の空欄へ、それぞれのサービスで取得したAPIキーを入れます。

```toml
OPENAI_API_KEY = "..."
ANTHROPIC_API_KEY = "..."
GEMINI_API_KEY = "..."
APP_PASSWORD = "好きな暗証番号"
SUPABASE_URL = "https://プロジェクトID.supabase.co"
SUPABASE_SECRET_KEY = "sb_secret_..."
```

`secrets.toml` は `.gitignore` に含まれています。**APIキー入りのこのファイルは絶対にGitHubへアップロードしないでください。**

`APP_PASSWORD` は公開したアプリを開くための暗証番号です。APIキーとは別の、推測されにくい文字列を設定してください。

`SUPABASE_URL` と `SUPABASE_SECRET_KEY` は履歴保存に使います。未設定でもAIへの質問はできますが、アプリを閉じた後に履歴は残りません。Secret keyは管理者権限を持つため、APIキーと同様にGitHubや画面へ絶対に公開しないでください。

### 4. 履歴保存を設定する

1. Supabaseでプロジェクトを作成します。
2. Supabaseの「SQL Editor」を開きます。
3. [`supabase_schema.sql`](supabase_schema.sql) の内容を貼り付けて実行します。
4. Project URLとSecret keyを、上記のSecretsへ設定します。

### 5. アプリを起動する

```bash
streamlit run app.py
```

表示されたURLをブラウザで開きます。終了するときはターミナルで `Ctrl + C` を押します。

## 使い方

1. 「いま何について考えたい？」へ質問を書きます。
2. 「3つのAIに聞く」を押します。
3. 3つの回答を読み、その下の「回答の違い」で共通点・差分・次に考える問いを確認します。
4. 回答の下の「この続きで考える」へ、掘り下げたい論点や思いついたことを書き、「3つのAIに続きを聞く」を押します。
5. 前の回までの質問・3AIの回答・比較を全員が参照し、それぞれの判断と理由で答えます。今回の回答は3AIが同時に生成するため、同じ回の他AIの回答は次の質問から参照します。
6. 「過去の質問を見る」から相談を開くと、翌日でも同じ入力欄から再開できます。以前の単発の履歴もそのまま続けられます。
7. 別のテーマを始めるときは「新しい相談」を押します。前の相談は履歴に残ります。

最新のやりとりを表示し、前の回は折りたたみで読み返せます。各回の質問原文・回答全文・要約・比較を保存します。
履歴の保存に失敗したときは、ページを閉じる前に「履歴の保存を再試行」を押してください。保存の再試行でAIは呼び出しません。

既存の `ai_history` テーブルのJSON欄に会話を保存するため、追加のSQLやSecrets設定は不要です。保存ごとに会話全体のコピーを追加し、一覧には各相談の最新状態を最大50件表示します。過去の保存行は上書きしません。
同じ相談を複数端末で同時に進めると、一覧から開くのは最後に保存した端末の会話になります。端末を切り替える際は履歴から開き直してください。

一部のAPIが失敗しても、成功したAIの回答は表示されます。2つ以上の回答が得られたときだけ比較分析を行います。

## AIの使用量を見る

画面上部の「AIの使用量」で、ChatGPT・Claude・Geminiそれぞれの今月のトークン数を確認できます。日本時間の月単位で、この機能の追加後に、このアプリがAPIから取得・記録できた分を集計します。ChatGPTには回答だけでなく要約・比較の使用量も含みます。

- 「月の目安を設定（任意）」にトークン数を入力すると、使用率と目安までの残りをメーター表示します。0は未設定です。
- 目安は画面を開いている間だけ保持します。契約上限や購入済み残高ではなく、超えてもAPI呼び出しを自動停止しません。
- Supabaseに履歴を保存していれば、使用量も翌日・別端末から確認できます。履歴の再表示・会話の継続・保存の再試行で同じ実行を二重加算しません。追加のSQLやAPIキーは不要です。
- 取得できなかった使用量は「未計測」または未取得件数として表示し、使用量ゼロとは扱いません。保存に失敗した分は、保存の再試行が成功するまで現在の画面だけに残ります。
- 過去の未計測分、他アプリでの使用、応答を受け取れなかった実行やSDKの自動再試行分などは集計できない場合があります。各社のアカウント全体の正確な請求額・残高ではありません。
- トークンはAIが読み書きした量の単位です。単価はモデルや入力・出力・キャッシュで異なるため、料金や実際の残高は各社の管理画面で確認してください。

## Streamlit Community Cloud で公開する

1. このフォルダをGitHubの新しいリポジトリへアップロードします。`secrets.toml` が含まれていないことを確認します。
2. [Streamlit Community Cloud](https://share.streamlit.io/) にログインし、「Create app」を選びます。
3. GitHubのリポジトリ、ブランチ、`app.py` を選んで公開します。
4. アプリ設定の「Secrets」を開き、ローカルと同じ3つのAPIキー、`APP_PASSWORD`、Supabaseの2項目を貼り付けて保存します。
5. 公開URLを開き、短い質問で動作を確認します。

## 注意点

- 初期モデル名は `config.py` にまとめています。提供元で利用可能なモデル名へ変更してください。
- 1回の質問で、3つの回答取得と比較分析を合わせて最大4回のAPI呼び出しを行います。
- 会話が長くなるほど、送信する情報量とAPI費用・保存容量が増えます。現在は履歴全文を渡し、送信文が10万文字を超える場合は原文を切らずに送信を止めます。その場合は要点をまとめて新しい相談を始めてください。
- 暗証番号を知っている人は同じ履歴を閲覧できます。個人用として、暗証番号を共有しないでください。
- 本格的なユーザー認証、ファイル添付、Web検索、回答の統合・順位付けは V0.1 の対象外です。
